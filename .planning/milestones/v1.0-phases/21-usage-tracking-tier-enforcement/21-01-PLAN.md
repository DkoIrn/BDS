    - checkUsageLimit returns { allowed: false, limitType, current, max, message } when at or over limit
    - checkUsageLimit returns { allowed: true } when max is null (unlimited)
  </behavior>
  <action>
    1. Create `src/lib/usage.ts`:
       - `TierLimits` interface: `{ maxProjects: number | null, maxQcChecksPerMonth: number | null, maxStorageBytes: number | null }`
       - `TIER_LIMITS` constant: Record<string, TierLimits> with free/pro/max/enterprise values per roadmap success criteria
       - `UsageData` interface: `{ projectCount: number, qcCheckCount: number, storageBytes: number }`
       - `UsageLimitResult` type: `{ allowed: true } | { allowed: false, limitType: string, current: number, max: number, message: string }`
       - `getCurrentBillingPeriodStart(anchorDate: string): Date` -- pure function, uses Math.min(anchorDay, daysInMonth) for edge cases. Given an anchor date, returns the most recent occurrence of that billing day. If today is before the anchor day this month, go back to previous month.
       - `getUserUsage(supabase: SupabaseClient, userId: string, billingPeriodStart: Date): Promise<UsageData>` -- 3 parallel queries:
         a. `supabase.from('projects').select('*', { count: 'exact', head: true }).eq('user_id', userId)` for project count
         b. `supabase.from('datasets').select('file_size').eq('user_id', userId)` then sum for storage
         c. `supabase.rpc('count_user_qc_checks', { p_user_id: userId, p_since: billingPeriodStart.toISOString() })` for QC checks
       - `checkUsageLimit(current: number, max: number | null, limitType: string, planName: string): UsageLimitResult` -- pure function. If max is null, return allowed. If current >= max, return not allowed with descriptive message like "You've reached the {max} {limitType} limit on your {planName} plan. Upgrade to increase your limit."
       - `formatStorageSize(bytes: number): string` -- helper for display (e.g., "8.5 MB of 10 MB")

    2. Create `supabase/migrations/00010_usage_tracking.sql`:
       - Add `billing_cycle_start TIMESTAMPTZ DEFAULT NOW()` column to profiles
       - Create `count_user_qc_checks(p_user_id UUID, p_since TIMESTAMPTZ)` RPC function:
         ```sql
         CREATE OR REPLACE FUNCTION count_user_qc_checks(p_user_id UUID, p_since TIMESTAMPTZ)
         RETURNS INTEGER AS $$
           SELECT COUNT(*)::INTEGER
           FROM validation_runs vr
           JOIN datasets d ON d.id = vr.dataset_id
           WHERE d.user_id = p_user_id
             AND vr.created_at >= p_since
             AND vr.status = 'completed';
         $$ LANGUAGE sql STABLE SECURITY DEFINER;
         ```
  </action>
