<task type="auto">
  <name>Task 1: Backend webhook dispatch service and validation pipeline integration</name>
  <files>backend/app/services/webhooks.py, backend/app/routers/validation.py</files>
  <action>
1. Create `backend/app/services/webhooks.py`:
   - `sign_payload(payload_str: str, secret: str) -> str`: HMAC-SHA256 signing using Python's `hmac` and `hashlib` modules. Returns hex digest.
   - `deliver_webhook(delivery_id: str, url: str, secret: str, event: str, data: dict) -> None`:
     - Build JSON payload: `{ "event": event, "data": data, "timestamp": ISO8601 }`
     - Sign with HMAC-SHA256 using the endpoint secret
     - POST to url with headers: `Content-Type: application/json`, `X-TruQC-Signature: sha256={signature}`, `X-TruQC-Event: {event}`
     - 10-second timeout
     - On success (2xx): update delivery record status='delivered', response_status, response_body (truncated to 1000 chars)
     - On failure: increment attempts. If attempts < 3, retry after backoff (5s, 30s). If attempts >= 3, mark status='failed'
     - Use `time.sleep()` for backoff delays (acceptable in FastAPI background task on Railway)
   - `dispatch_webhooks(dataset_id: str, event: str, payload: dict) -> None`:
     - Get org_id by joining dataset -> jobs -> projects
     - Query `webhook_endpoints` where org_id matches, active=True, and event is in the endpoint's events array
     - For each matching endpoint: create a `webhook_deliveries` record with status='pending', then call `deliver_webhook`
     - Wrap entire function in try/except to never crash the validation background task

2. Modify `backend/app/routers/validation.py` `run_validation_background`:
   - Import `dispatch_webhooks` from `app.services.webhooks`
   - After successful validation (status update to 'validated'), call:
     ```python
     dispatch_webhooks(dataset_id, "validation.completed", {
       "dataset_id": dataset_id,
       "run_id": run_id,
       "total_issues": total_issues,
       "critical_count": critical_count,
       "pass_rate": pass_rate,
     })
     ```
   - After failed validation (in the except block, after status update to 'error'), call:
     ```python
     dispatch_webhooks(dataset_id, "validation.failed", {
       "dataset_id": dataset_id,
       "error": str(e),
     })
     ```
   - Wrap dispatch calls in their own try/except so webhook failures never affect validation status
  </action>
