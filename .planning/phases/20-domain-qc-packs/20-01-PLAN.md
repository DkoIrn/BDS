       - rule_type: "kp_drift"

       - Reuse `_find_coord_columns` pattern
       - For each consecutive row pair: compute coordinate distance in meters
       - Flag when distance > max_segment_distance. Message: "Segment distance of {dist:.1f}m between rows {i} and {i+1} exceeds maximum ({max:.1f}m). Possible data gap or coordinate error"
       - Also flag backtracking: if KP decreases while distance is large, message adds "with KP backtracking"
