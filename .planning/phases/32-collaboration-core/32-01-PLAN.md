    1. Create `src/lib/actions/notifications.ts` following existing server action patterns (createClient, getUser, requireOrgRole):
       - getNotifications(limit?: number): Fetch notifications for current user, join actor profile (actor_id -> profiles.full_name), order by created_at DESC, limit default 20. Return NotificationWithActor[].
       - getUnreadCount(): SELECT count(*) from notifications WHERE user_id = current AND read = FALSE. Return number.
       - markRead(notificationId: string): UPDATE notifications SET read = TRUE WHERE id = notificationId AND user_id = current. Return success/error.
       - markAllRead(): UPDATE notifications SET read = TRUE WHERE user_id = current AND read = FALSE. Return success/error.
       - createNotification(params: { userId, orgId, type, title, body?, resourceType?, resourceId?, linkUrl?, actorId }): INSERT into notifications. Used internally by other actions. Return success/error.

UPDATE issue_comments SET resolved_at = new Date().toISOString(), resolved_by = current user id WHERE id = commentId. Then call createNotification for the comment author with type 'comment_resolved', title "[Your Name] resolved your comment", resource_type 'issue', resource_id = issue's id, link_url built from issue context. Return updated comment.
       - Add reopenComment(commentId: string): UPDATE issue_comments SET resolved_at = NULL, resolved_by = NULL WHERE id = commentId. Return success/error.

'all' returns everything. Join resolved_by profile: select('*, profiles:user_id(full_name), resolver:resolved_by(full_name)').
