    2. Create src/app/api/certificates/route.ts:
       - Follow exact pattern from src/app/api/reports/pdf/route.ts.
       - Export async function POST(request: Request):
         a. Parse JSON body: { runId: string }.
         b. Authenticate user via createClient() + supabase.auth.getUser(). Return 401 if not authenticated.
         c. Get user's org membership from org_members table (same pattern as reports route).
         d. Get org name from organisations table.
         e. Proxy POST to `${FASTAPI_URL}/api/v1/certificate/generate/${runId}` with body { user_id, org_id, org_name }.
         f. If FastAPI returns non-200, forward the error status and message.
         g. Stream PDF response back with correct headers (content-type: application/pdf, content-disposition from FastAPI response).
       - Handle errors with try/catch, return NextResponse.json({ error }) on failure.

       - Props: { runId: string, criticalCount: number, status: string }

       - Button styled as outline variant with emerald/teal accent (matches brand).
       - On click:
         a. Set generating=true state, disable button, show loading spinner.
         b. POST to /api/certificates with { runId }.
         c. On success: create blob URL, trigger download with anchor click pattern (same as export-buttons.tsx).
         d. Extract filename from content-disposition header if present, fallback to "TruQC-Certificate.pdf".
         e. On error: show toast via sonner with error message.
         f. Set generating=false.
