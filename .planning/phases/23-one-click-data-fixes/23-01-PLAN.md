<objective>
Build the one-click fix engine as individual, testable functions that preview and apply three fix types: fill missing values, remove duplicates, and smooth spikes. Each function operates on raw data (string[][]) and returns a FixResult with the updated dataset, a before/after preview, and an undo snapshot.

Purpose: Decomposes the monolithic autoClean() into targeted fix functions users can apply one at a time with preview. The existing algorithms in auto-clean.ts are reused -- this is extraction + preview wrapper, not reimplementation.

Output: fix-types.ts (shared types), fix-engine.ts (6 functions: preview + apply for each fix type), fix-engine.test.ts (unit tests)
</objective>

  <behavior>
    - previewFillMissing(data): scans numeric columns for empty cells, returns FixPreview with interpolated values WITHOUT modifying input data
    - applyFillMissing(data): deep-copies data, fills missing values, returns FixResult with {data, preview, undoSnapshot}
    - previewRemoveDuplicates(data): identifies exact duplicate rows, returns FixPreview showing which rows would be removed
    - applyRemoveDuplicates(data): deep-copies data, removes duplicate rows keeping first occurrence, returns FixResult
    - previewSmoothSpikes(data): detects outlier values (z-score > 4), returns FixPreview with replacement values
    - applySmoothSpikes(data): deep-copies data, replaces spikes with neighbor median, returns FixResult
    - All preview functions: input data is NOT mutated (verified by comparing before/after reference)
    - All apply functions: undoSnapshot matches original input data
    - Edge case: empty dataset (< 2 rows) returns empty preview with 0 affected rows
    - Edge case: no issues found returns FixPreview with totalAffected = 0
  </behavior>
  <implementation>
    1. Create fix-types.ts with FixType union, FixPreview, FixResult, UndoEntry interfaces per research spec
    2. Export findKpColumn and detectNumericColumns from auto-clean.ts (currently private functions -- add export keyword)
    3. Create fix-engine.ts with 6 functions (preview + apply for each of 3 fix types), reusing detection logic from auto-clean.ts
    4. Each preview function: reads data without mutation, collects affected rows with before/after values
    5. Each apply function: deep-copies input as undoSnapshot, applies fix, builds preview, returns FixResult
    6. All algorithms directly extracted from existing auto-clean.ts (interpolateGaps, removeDuplicates, removeSpikes) -- same logic, different return shape
  </implementation>
